Quickstart

Install pac, compile a standalone LLVM binary from Python syntax, bridge NumPy through a typed .paw module, and bundle a relocatable release.

01

Install & verify toolchain

Requires Linux x86-64, gcc, and CPython 3.11–3.13 with development headers and a shared libpython (e.g. uv python install 3.12).

shell 
$ pip install pa-lang
$ pac doctor

pac doctor checks gcc, llvmlite, Python.h, and shared libpython before your first build.

02

Compile your first native binary

Save hello.pa. Function bodies carry zero type annotations—declare only the return type (-> T), and bidirectional inference resolves the rest.

hello.pa 
01def sum_squares(xs) -> float:
02    total = 0.0
03    for x in xs:
04        total = total + x * x
05    return total
06
07def main() -> int:
08    data = [1.0, 2.0, 3.0, 4.0]
09    print(sum_squares(data))
10    return 0
build & run 
$ pac check hello.pa
$ pac build hello.pa -o hello && ./hello
30.0
Pure .pa binaries link zero Python runtime. data compiles to a stack-allocated [4 x double].
03

Structs, borrowing & mut()

Containers and @struct records are passed as zero-copy read-only borrows. Any callee that mutates a parameter requires an explicit mut(...) at the call site (PA_E050).

vec_ops.pa C layout · AoS 
01@struct
02class Point:
03    x: float
04    y: float
05
06def scale_all(pts, factor) -> void:
07    for i in range(len(pts)):
08        pts[i].x = pts[i].x * factor
09        pts[i].y = pts[i].y * factor
10
11def main() -> int:
12    pts = [Point(x=1.0, y=2.0), Point(x=3.0, y=4.0)]
13    scale_all(mut(pts), 2.5)
14    print(pts[0].x, pts[1].y)
15    return 0
FORM STORAGE & LIFETIME
[0.0] * 16 Fixed stack array [16 x f64] (constant N, ≤ 64 KB)
[0.0] * n Contiguous heap Vec[float], auto-freed by RAII at scope exit
[0] * 0 / [0.0] * 0 Typed empty dynamic Vec (100% valid Python)
a[len(a) - 1] Bounds-checked in dev; negative indexes (a[-1]) are rejected
04

Bridge Python libraries with .paw

Native .pa files cannot import third-party Python packages (PA_E001). Quarantine them in a .paw crossing module with locked In -> Out signatures.

stats.paw crossing zone 
import numpy as np

def percentile(arr: span[float], q: float) -> float:
    view = np.frombuffer(arr, dtype=np.float64)
    return float(np.percentile(view, q))
main.pa native zone 
import stats

def main() -> int:
    vals = [10.0, 20.0, 30.0, 40.0, 50.0]
    print(stats.percentile(vals, 90.0))
    return 0
  • span[T] crosses via read-only PyMemoryView_FromMemory (zero copy).
  • Calling a .paw function inside a loop is rejected (PA_E002)—pack batches on the Pa side first.
  • .paw sources are embedded in the binary at build time; use PA_PATH to live-override during dev.
05

Dev vs. prod & AI repair tickets

Develop with --mode dev (default) for bounds checks, deep .paw static lint, and full boundary customs. Switch to --mode prod once dev is green.

check & build modes 
# Emit self-contained JSON repair tickets for AI agents
$ pac check --ai-diagnostic .

# Ship lean native binary once dev checks pass
$ pac build main.pa --mode prod -o app

Any runtime or boundary violation exits with code 70 and writes pa_runtime_fault.json or pa_boundary_fault.json with a replayable payload snapshot.

06

Relocatable binaries & shared libraries

To deploy a .paw-enabled binary to another machine, build with --relocatable and bundle libpython + trimmed stdlib next to the executable (found automatically via $ORIGIN rpath).

deploy 
$ pac build main.pa --mode prod --relocatable -o app
$ pac doctor ./app
$ pac bundle ./app --with-stdlib
RUNTIME RESOLUTION & TROUBLESHOOTING
  • Embedded .paw sources: compiled binaries embed imported .paw files (no hard-coded source paths). Set PA_PATH=dir1:dir2 to prefer live .paw files while developing.
  • Python discovery order: home PA_PYTHON_HOME > PYTHONHOME > ./python-home > build-time default; packages PA_PYPATH > $VIRTUAL_ENV site-packages. Pure-native programs (no .paw) link no Python at all.
  • Missing libpython or stdlib: a missing libpython fails in the dynamic loader (exit 127); run pac doctor ./app and pac bundle ./app --with-stdlib. An unusable Python home produces a friendly "direction": "STARTUP" fault (exit 70) in pa_boundary_fault.json (override path with PA_FAULT_PATH).
FRAMEWORK SHELLS (FASTAPI / FLASK / STREAMLIT)

Compile @export functions with pac build lib.pa --shared -o lib.so. Faults are caught by a setjmp guard and exposed via pa_error_code() without crashing the host server.

07

AI skills & editor tooling

Print any SKILL.md straight to stdout for your agent, or install all three skills into Claude Code, Cursor, Codex, or Antigravity in one command:

pac skill 
$ pac skill --list                # list bundled skills
$ pac skill pa-coder              # print SKILL.md to stdout (or `pac skill` for all)
$ pac skill --install claude      # install to .claude/skills/ (+ --global for ~/)
$ pac skill --install cursor      # also supports: codex, copilot, github, antigravity, or <dir>
pa-coder

Scaffold new Host-First projects, contiguous structs, and .paw boundaries.

py-to-pa

Triage Python modules, invert control to Pa, and verify via differential tests.

cpp-to-pa

Map std::vector, std::span, and structs one-to-one to readable Pa code.
